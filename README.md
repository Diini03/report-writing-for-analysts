# Report Writing for Data Analysts

A free, public course on the skill most data courses skip: turning a dashboard into a report that leads to a decision.

Most tutorials teach the _building_ side of analytics, Excel, SQL, Python, Power BI. Very few teach the _communication_ side, taking what you built and explaining what it means and what should happen next. That gap is where a lot of technically capable analysts get stuck, in interviews and on the job.

This repository is that missing course, free to read, fork, and learn from.

## Who this is for

Self-taught and bootcamp-trained data analysts who can already build a dashboard, but aren't sure what to do when asked to write a report on top of it.

## What you'll learn

By the end of this course you'll be able to:

- Explain the difference between a dashboard and a report, and why it matters
- Choose the right type of analytical report for a given situation
- Structure a report the way a professional analyst would, from title to limitations
- Write findings and recommendations with clarity and precision
- Communicate a report inside a BI tool, and answer reporting questions confidently in an interview

## How to start

Read the five lessons in order, starting with [Lesson 1](lessons/01-understanding-reports.md). Each lesson is short and standalone, but builds on the one before it.

## Repository structure

```
report-writing-for-analysts/
├── lessons/        the course itself, read these in order
├── examples/        short, standalone sample reports for quick reference
├── templates/        blank, reusable report structures to fill in yourself
└── case-study/        a full dataset-to-dashboard-to-report walkthrough
```

### Lessons

The five lessons above. Each one teaches a single idea in full, using public, widely known datasets, so the ideas are never abstract.

### Examples

See [`examples/`](examples). Short, finished reports you can read in a few minutes, each demonstrating one report type from Lesson 2 applied using the structure from Lesson 3. No dataset or dashboard attached, these are for quick reference.

### Templates

See [`templates/`](templates). A blank version of the six-part report structure from Lesson 3. Copy it, rename it, and fill it in for your own project.

### Case study

A complete, real-world walkthrough: a public dataset, taken through a dashboard, into a full written report following this course's structure. This is the proof that the course works end to end, not just a reference, a fully worked project. In progress, and will be linked here once published.

## Learning outcome

After working through this course, you should be able to look at any dashboard you've built and produce a clear, structured, decision-ready report on top of it, the kind that holds up in a real interview or on a real team.

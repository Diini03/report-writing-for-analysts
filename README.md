# Report Writing for Data Analysts

A free, lesson-based course on the one skill most data courses skip: **turning a dashboard into a report that leads to a decision.**

Most tutorials teach you Excel, SQL, Python, Power BI — the *building* side of analytics. Almost none teach the *communication* side: how to take what you built and tell someone what it means and what to do about it. That gap is exactly where a lot of analysts get stuck in interviews and on the job.

This repo is that missing course. Free, public, built to learn from and to teach others.

## Who this is for

Self-taught and bootcamp-trained data analysts who can already build a dashboard, but freeze when asked *"okay, now write me a report on this."*

## How it's structured

Each lesson is short, standalone, and built around real, famous datasets (Titanic, Netflix, COVID-19, retail sales) so the ideas are never abstract — you see them applied.

| # | Lesson | What you'll learn |
|---|--------|--------------------|
| 1 | [What is a Report?](lessons/01-what-is-a-report.md) | Dashboard vs report, the Audience–Insight–Action framework |
| 2 | Types of Reports | Which report to write for which situation |
| 3 | Anatomy of a Report | The skeleton every good report follows |
| 4 | Reports Inside Power BI | Where reporting actually lives in the tool — tooltips, bookmarks, paginated reports, export |
| 5 | Writing It — Sentence Level | Weak vs strong report writing, rewritten line by line |
| 6 | Full Practice Run | Real dataset → dashboard → full written report |

New lessons are added one at a time as the course is built out.

## How to use this repo

Read the lessons in order. Each one ends with a short check — answer it in your own words before moving to the next lesson. This isn't a reference doc to skim; it's meant to be worked through.

# Contributing

This repository is the official, maintained source for the Report Writing for Data Analysts course. It's read-only for the public, nobody besides the repository owner has direct push access, but improvements are welcome through pull requests.

## How to contribute

1. Fork this repository
2. Clone your fork locally
3. Create a new branch for your change
4. Make your changes
5. Commit your changes with a clear message
6. Push the branch to your fork
7. Open a pull request against this repository
8. The repository owner will review it, and merge it if it fits

Submitting a pull request does not guarantee it will be merged. Changes are reviewed for accuracy, clarity, and fit with the rest of the course before being accepted.

## What's worth contributing

- Corrections to factual or technical errors
- Fixing broken links
- Improving an explanation that's unclear
- Improving or adding an example, using public, widely known data, not personal or proprietary datasets
- Suggesting a useful resource
- Improving documentation
- Reporting a problem, even if you can't fix it yourself, by opening an issue

## What to avoid

- Large structural changes to the course without discussing them first in an issue
- Adding personal projects or promotional content into the lessons or examples
- Submitting AI-generated content that hasn't been reviewed and edited for accuracy

## Reporting a problem

If you notice an error but aren't able to submit a fix yourself, opening an issue describing the problem is just as useful as a pull request.
